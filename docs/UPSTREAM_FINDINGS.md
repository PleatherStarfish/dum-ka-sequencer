# Upstream Findings

Findings about `carnatic-seq` are recorded here and are never fixed in the source repository. Entries 1–17 are seeded from extraction-plan §10.

1. **Track-import regression** (bisected to `fcd1e4f`): `handleImportTrack` exits through roughly eight silent early-return guards. The prime suspect is fingerprint asymmetry between `buildPatchDocument()` and `currentAuthoredPatchFingerprintRef`, plausibly aggravated by later seed-string changes. Five sibling handlers may share the problem. The guards do not surface errors.
2. Track-envelope version acceptance is discontinuous (`{3,6,7,8}`), so v4/v5 files are rejected.
3. `cseq-transport/src/lib.rs` has 40,997 lines, 54% of them inline tests.
4. Seed infrastructure is duplicated: SplitMix64 three times, `mix_seed` twice, and Drift/Morph implementations twice with divergent helper names.
5. `src-tauri` bypasses `cseq-persist`; patch/track validation is hand-rolled in `main.rs`, leaving two persistence systems.
6. Generated junk is committed: two `_tmp_19_*` files, two Vite timestamp bundles, and `test-results/.last-run.json`; `.claude/worktrees` is only locally excluded.
7. `examples/scores/*.json` are both serialization fixtures and golden-ledger inputs, creating hidden regeneration coupling.
8. The `fuzzing` Cargo feature is load-bearing for normal invariant/golden tests and the benchmark crate.
9. Five bridge wrappers have no UI callers; three still have live Tauri commands.
10. `ui/src/styles.css` is a single 25,400-line file.
11. `PitchNotation.tsx` is a misnamed grab-bag containing timeline, e2e, matrix-heat, and transport constants used by unrelated kept features.
12. `useChannelShaperState.tsx` is a god-hook with 161 `useState` calls, including unrelated main-editor, velocity, and automation state.
13. `PitchTab` declares five tabs but only three render; `transpose` and `seeds` are dead IDs.
14. `cseq-bench/Cargo.toml` has a stale rayon rationale comment because transport itself now uses rayon.
15. `ARCHITECTURE.md` omits `cseq-jathi-bhedam`, `cseq-trigger`, and `cseq-bench` from its repository layout.
16. CI runs Vitest on Node 20 while project docs say local jsdom suites need Node 22; the discrepancy is unverified.
17. `docs/` mixes about 30 one-shot CODEX/CLAUDE review prompts with durable design documentation (101 files total).

## Findings added during extraction

18. **Global/custom BPM routing regression.** In mock e2e, editing global BPM while the active track uses custom BPM still sends the custom track BPM (`123`) through `transport_set_tempo` twice, contaminating the global/reference transport clock. Stable across two full mock runs.
19. **Rich patch roundtrip shape mismatch.** The schema-v8 save path expands a sparse ratchet time-curve choice into the full default choice catalog, making the launch-critical rich-patch e2e fail its saved-shape assertion. Stable across two full mock runs.
20. **Stale-preview parity test races its held request.** The mock timeline parity test reads `pendingPreviewCycles` as soon as timeline sources become incoherent, before the debounced cycle-1 preview request necessarily enters the driver queue. It therefore sees `[]` and fails before proving that rows remain mounted; polling for the held request makes the unchanged product path pass.
21. **Real-backend gati test inspects a stale command capture.** The test authors subdivision 7 while stopped, which updates `score_preview_subdivision_switch`; its assertions instead read the startup-only `lastScoreCreateRequest` and therefore see subdivision 4 even though the real preview and rendered timeline are already subdivision 7. The assertion must inspect `lastPreviewRequest.request` until Play applies score creation.
22. **Parallel batch/stepped realization has a bounded equivalence domain.** Upstream's invariant suite explicitly excludes triggered/Track-Flow and custom-tempo cases from byte-identical batch-versus-stepped assertions because source-history exposure and cross-cycle deferral differ by batch. Those cases are guaranteed note-balanced, but not batching-identical; the P4 generator matrix reproduced the custom-tempo residual unchanged.
23. **Sample-score regeneration is byte-nondeterministic.** The ignored `cseq-model` generator serializes `DurationTree.nodes` from `HashMap`, so a no-op regeneration reorders nodes in five of six checked-in scores. Parsed values remain equal, but the churn obscures the one semantic fixture change and makes byte-level review unreliable.
24. **Fresh-launch track import has no parallel-project destination.** The editor renders its initial track from flat state, but `parallelProjectRef.current` remains `null` until a project is explicitly applied. `handleImportTrack` reads that ref before building a patch and silently returns, so its later fingerprint guard is unreachable on the default launch path.
25. **Fresh-launch metadata controls silently no-op.** Mute, solo, and rename call `updateParallelProjectMetadata`, which returns without status when `parallelProjectRef.current` is still `null`. The rendered initial track therefore exposes controls that do nothing until another action applies a project.
26. **Real-backend e2e harness isolation is incomplete.** The support process inherits `CAESURA_MACHINE_DIR`, attaches to a fixed `39600 + worker` port without proving ownership, and never removes its per-run temp directory. A stale harness or developer environment can therefore contaminate a supposedly isolated test run.
27. **The committed parallel fuzz seed crashes in the fuzz input builder.** `fuzz/corpus/parallel_transport_queue/seed-0` drives `common::custom_subdivision` to emit positive equal-parts weight with no part-count choice; `Score::subdivision_switch` then panics with `custom subdivision needs a positive part-count weight` before transport is exercised. The same helper and byte-identical seed are present at `be8b1b8`, so the scheduled fuzz smoke is deterministically red rather than finding a product fault.
28. **The mock automation sampler does not implement the production combine contract.** `ui/tests/e2e/support/mockTauri.ts` samples only the first enabled curve on each track, ignores marker anchors and multi-curve/track replace-add-multiply composition, and invents `cycle + beat / cycleBeats` when a curve has no sample. A mock parity test can therefore pass with values the Rust sampler would never produce.
29. **The live parallel-runtime gate ignores Track Flow boxes and hidden trigger sources.** `App.tsx` derives `parallelPlaybackRuntimeEnabled` from `parallelRuntimeWouldEngage(project.tracks)`, while `buildParallelPlaybackRequest` also engages for any audible Track Flow lane and for silent source clocks. Live configuration pushes can therefore be gated for the wrong runtime topology.
30. **Track Flow live rhythm rows filter against the wrong identity.** Transport tags a Track Flow source's realized-rhythm events with its synthetic `track-flow-<box>` lane id, but `selectRealizedRhythmBySpanId` filters them against the active authored track id. While a boxed track plays, its live rhythm/generator row can drop the realized events that drove audio and fall out of parity.
31. **Stable e2e CI omits bootcheck and can cancel its own nightly coverage.** The e2e workflow runs mock Playwright but not the repository's isolated bootcheck configuration. Its concurrency key contains only `github.ref`, so a push to `main` can cancel a scheduled/manual run that is responsible for the bounded fuzz, chaos, and macOS lanes.
32. **The mutation pilot fails open when its harness breaks.** `scripts/mutants.sh` converts every `cargo mutants` failure to a message, reports a missing `outcomes.json`, and still exits zero. A broken baseline, invocation error, or zero-result run can therefore look like a successful report-only mutation pass.
33. **Rust CI's coverage substitution does not include future doctests by default.** The workflow says `cargo llvm-cov --workspace` replaces `cargo test --workspace`, but cargo-llvm-cov requires its separate unstable `--doctests` flag to include doc tests. The pinned source currently has no executable Rust doctests, so this is future-drift exposure rather than a present missing test.
